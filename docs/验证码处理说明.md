# B站验证码处理说明

## 什么是验证码错误？

当B站检测到账号操作频率过高或行为异常时，会要求进行验证码验证。系统会返回一个验证码URL，需要手动完成验证。

## 验证码URL格式

验证码URL通常格式如下：
```
https://api.bilibili.com/x/v1/captcha/get?bid=reply&token=xxxxxxxxxxxxx
```

或者可能是完整的验证码页面URL。

## 如何使用验证码URL

### ⚠️ 重要说明

**验证码URL通常只返回一张图片，不是交互式页面。** 这是因为B站的验证码需要通过网页版或APP来完成交互式验证。

### 推荐方法：在B站网页版完成验证（最简单有效）

1. **访问B站网页版**
   - 打开 https://www.bilibili.com
   - **重要**：确保已登录，且使用的是与机器人配置中**相同的B站账号**

2. **触发验证码**
   - 在B站进行一些操作来触发验证码，例如：
     - 尝试发送一条评论
     - 尝试点赞或收藏视频
     - 尝试发送私信
   - 系统会弹出验证码页面（通常是滑块验证码）

3. **完成验证码验证**
   - 按照页面提示完成验证码
   - 如果是滑块验证码：拖动滑块到缺口位置
   - 如果是图形验证码：点击正确的图片
   - 验证成功后，页面会显示验证成功

4. **等待冷却期结束**
   - 验证完成后，系统会进入冷却期（默认2小时）
   - 冷却期结束后，系统会自动恢复正常运行
   - 可以在日志中查看冷却期剩余时间

### 方法二：查看验证码图片（仅供参考）

如果验证码URL返回的是图片：

1. **复制验证码URL**
   - 从日志中找到类似这样的信息：
   ```
   [验证码错误] 验证码URL: https://api.bilibili.com/x/v1/captcha/get?bid=reply&token=xxx
   ```

2. **在浏览器中打开**
   - 复制完整的URL
   - 在浏览器中打开，会显示验证码图片
   - **注意**：这只是图片，无法直接在这里完成验证

3. **需要配合网页版验证**
   - 这个图片只是参考
   - 实际验证需要在B站网页版完成（见方法一）

### 方法三：等待冷却期自动结束（最简单）

如果不想手动验证：

1. **什么都不做**
   - 系统会自动进入冷却期（默认2小时）
   - 冷却期结束后，系统会自动恢复正常运行

2. **查看冷却期状态**
   - 查看日志文件，会显示剩余时间：
   ```
   [验证码冷却] 当前在验证码错误冷却期内，暂停所有评论检查和回复。剩余时间: 37.9 分钟
   ```

## 验证码错误后的处理流程

1. **系统检测到验证码错误**
   - 记录错误时间
   - 进入冷却期（默认2小时）
   - 暂停所有回复操作

2. **手动完成验证码验证**
   - 按照上述方法完成验证

3. **等待冷却期结束**
   - 冷却期结束后，系统自动恢复
   - 无需重启程序

## 注意事项

1. **使用相同账号**
   - 验证码验证时，必须使用与机器人配置中相同的B站账号
   - 确保浏览器中已登录正确的账号

2. **验证码有效期**
   - 验证码URL通常有时效性
   - 如果URL过期，可以等待冷却期结束后重试

3. **冷却期设置**
   - 默认冷却期为2小时（7200秒）
   - 可在 `data/config/adapters.ini` 中修改 `captcha_cooldown_seconds` 参数
   - 建议设置为1-3小时（3600-10800秒）

4. **手动清除冷却期**
   - 如果需要立即恢复（不推荐），可以删除文件：
   ```
   data/bilibili/captcha_error_time.json
   ```
   - 删除后重启程序即可立即恢复

## 预防验证码错误

1. **降低回复频率**
   - 增加 `reply_interval`（回复间隔，单位：秒）
   - 降低 `max_replies_per_hour`（每小时最大回复数）

2. **增加回复间隔**
   - 建议将 `reply_interval` 设置为至少30秒
   - 避免短时间内大量回复

3. **降低回复率**
   - 调整 `min_response_willingness`（回复意愿阈值）
   - 只回复真正需要回复的评论

## 在B站网页版也显示验证码错误怎么办？

如果你在B站网页版操作时也显示验证码错误，说明账号已经被B站标记，需要采取以下措施：

### 解决方案

1. **停止所有操作，等待一段时间**
   - 立即停止机器人的所有操作
   - 停止在B站网页版的手动操作
   - 等待至少2-4小时，让账号"冷却"

2. **清除冷却期记录（如果需要）**
   - 删除文件：`data/bilibili/captcha_error_time.json`
   - 重启机器人程序
   - **注意**：清除后不要立即恢复操作，建议等待更长时间

3. **降低操作频率**
   - 修改配置文件 `data/config/adapters.ini`：
     ```ini
     reply_interval = 60  # 增加到60秒或更长
     max_replies_per_hour = 10  # 降低到每小时10条或更少
     ```
   - 重启程序

4. **等待账号恢复**
   - 通常需要等待4-24小时
   - 期间不要进行任何操作
   - 等待时间越长，恢复越快

5. **验证账号状态**
   - 等待一段时间后，在B站网页版尝试简单的操作（如点赞）
   - 如果不再要求验证码，说明账号已恢复
   - 此时可以重新启动机器人

### 预防措施

- **降低回复频率**：增加回复间隔，减少每小时回复数
- **避免高峰期操作**：避开B站用户活跃的高峰时段
- **分散操作时间**：不要集中在短时间内大量操作

## 常见问题

**Q: 验证码URL只显示一张图片，没有输入框怎么办？**
A: 这是正常的。验证码URL只返回图片，实际验证需要在B站网页版完成。请访问 https://www.bilibili.com，登录后尝试发送评论或点赞，会弹出验证码页面，在那里完成验证即可。

**Q: 在B站网页版也显示验证码错误怎么办？**
A: 这说明账号已经被B站标记。应该：
1. 立即停止所有操作
2. 等待至少2-4小时
3. 降低操作频率配置
4. 等待账号恢复后再重新启动

**Q: 验证码URL打不开怎么办？**
A: 可以直接在B站网页版手动触发验证码（发送评论、点赞等），或等待冷却期结束后重试。

**Q: 验证完成后多久能恢复？**
A: 验证完成后，需要等待冷却期结束（默认2小时）。冷却期结束后系统会自动恢复。

**Q: 可以提前结束冷却期吗？**
A: 可以删除 `data/bilibili/captcha_error_time.json` 文件并重启程序，但不推荐，因为可能导致再次触发验证码。如果账号已经被标记，建议等待更长时间。

**Q: 如何查看冷却期剩余时间？**
A: 查看日志文件，会显示类似这样的信息：
```
[验证码冷却] 当前在验证码错误冷却期内，暂停所有评论检查和回复。剩余时间: 37.9 分钟
```

**Q: 必须手动验证吗？可以自动处理吗？**
A: 目前B站的验证码（特别是滑块验证码）需要人工交互，无法完全自动化。最简单的方法是等待冷却期结束，系统会自动恢复。

**Q: 账号被标记后多久能恢复？**
A: 通常需要4-24小时，具体时间取决于账号的操作历史和B站的判定。建议等待至少4小时后再尝试操作。
